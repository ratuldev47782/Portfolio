## Overview

A multi-module ERP system that gives a garment factory's production, quality, maintenance, and industrial
engineering teams a shared, real-time view of the shop floor. It is deployed and running in production at HKD
Outdoor Innovations Ltd.

- **GitHub**: [ratuldev47782/Production-Quality-ERP-V-2.0](https://github.com/ratuldev47782/Production-Quality-ERP-V-2.0)
- **Live demo**: [hkd-production-quality-erp.vercel.app](https://hkd-production-quality-erp.vercel.app/)
- **Demo login**: user `Ratul` / password `123456`

## Modules

- **Production** — line-wise hourly target vs. achievement tracking, automated efficiency percentage calculation,
  and style-wise WIP visibility, surfaced through real-time shop-floor dashboards built for TV displays with
  auto-refresh.
- **Quality** — hourly defect logging, RFT% and DHU% reporting, and top-defect ranking by line and date, so quality
  decisions are driven by the last hour of data instead of end-of-day summaries.
- **Maintenance** — a complete machine inventory with serial-number tracking, floor-wise placement, and live status
  management (Running / Idle / Repairable / Damage).
- **Industrial Engineering (IE)** — process-wise machine line layout planning that calculates targets from SMV,
  efficiency, and manpower inputs, synced live with machine status.

## Access control

Role-based access control spans the Production, Quality, Maintenance, IE, and Management teams, with building-level
data isolation and kiosk-friendly persistent sessions for shop-floor devices.

## Technologies used

- **Next.js (App Router)** and **React** for the dashboards and operator screens.
- **Express.js** for the API, with **MongoDB and Mongoose** for the operational data model.
- **Recharts** for efficiency, defect, and target-vs-achievement charts.
- **Tailwind CSS and DaisyUI**, **Framer Motion**, **Cloudinary**, and **JWT** for UI, assets, and authentication.

## Outcome

Production, quality, maintenance, and IE now work from the same live data. Hourly targets, defect rates, and machine
status are visible on the floor as they happen rather than being reported after the fact.
